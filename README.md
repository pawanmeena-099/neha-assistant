# NEHA

Next-generation Personal AI Assistant

## Vision
NEHA is a hybrid local and cloud AI assistant
designed for desktop and mobile platforms.

## Core Capabilities
- Hybrid AI (Local + Cloud)
- Intelligent Task Orchestration
- Long-term Memory
- Autonomous Coding Agent
- Multi-Agent System
- OS Automation
- Continuous Learning
- Voice and Vision
- Security and Permission Management

## Technology Stack
- Python
- FastAPI
- Ollama
- PostgreSQL
- React
- Tauri
- Kotlin
- GitHub
